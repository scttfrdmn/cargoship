# CargoShip Assets

This directory contains visual assets for the CargoShip project.

## Images

- `images/logo.png` - Main project logo (cargo ship with containers and cloud)
- `images/logo-small.png` - Smaller version for favicons and icons
- `images/banner.png` - Wide banner version for documentation headers

## Usage

### In Documentation
```markdown
![CargoShip Logo](../assets/images/logo.png)
```

### In HTML
```html
<img src="assets/images/logo.png" alt="CargoShip Logo" width="200">
```

## Logo Guidelines

- The logo represents CargoShip's mission of efficient cloud storage transportation
- Primary colors: Navy blue (#1e3a5f), Orange/Red containers, Light blue clouds
- Use the full logo for headers and primary branding
- Use the small version for favicons and compact spaces
- Maintain aspect ratio when resizing
