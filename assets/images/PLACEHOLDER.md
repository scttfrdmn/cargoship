# CargoShip Logo Assets

This directory contains the CargoShip project logos.

## Required Files

Please add the following logo files to this directory:

- `logo.png` - Main project logo (recommended: 400x400px or larger)
- `logo-small.png` - Small version for favicons (64x64px)  
- `logo-banner.png` - Wide banner version for headers
- `favicon.ico` - Website favicon (converted from logo)

## Source Image

The source image shows:
- A cargo ship with the name "CARGOSHIP" on the hull
- Colorful shipping containers (orange, red, green)  
- A cloud background with a small flag
- Navy blue ship on stylized water waves
- Overall maritime/shipping theme representing data transportation

## Usage Instructions

1. Save the provided logo image as `logo.png`
2. Create smaller versions for different use cases
3. Generate favicon.ico for web applications
4. Update documentation references to use new logo paths

The logo represents CargoShip's mission of efficiently transporting data to cloud storage, combining the reliability of maritime shipping with modern cloud infrastructure.
