# Documentation Header Template

Use this template for consistent documentation headers across the CargoShip project:

## For Main Documentation Pages

```markdown
<div align="center">
  <img src="../assets/images/logo.png" alt="CargoShip Logo" width="120" height="120">
  <h1>Document Title</h1>
  <p>Document description</p>
</div>
```

## For Subdirectory Documentation 

```markdown
<div align="center">
  <img src="../../assets/images/logo.png" alt="CargoShip Logo" width="100" height="100">
  <h1>Document Title</h1>
</div>
```

## For README Files in Subdirectories

```markdown
![CargoShip Logo](../assets/images/logo.png)

# Directory Title
```

## Style Guidelines

- Main documentation: 120x120px logo
- Subdirectory docs: 100x100px logo  
- README files: Full size, left-aligned
- Always include alt text: "CargoShip Logo"
- Use relative paths from document location
